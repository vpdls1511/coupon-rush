모든 대화에대한 답변, 진행사항 안내는 한글로 해야해.

TeamCreate로 에이전트 팀을 생성해서진행해줘.

각 팀별로 나누어서 비즈니스 로직 분석, 아키텍처 설계, 기능 구현, 코드리뷰를 진행해줘.
각 팀원들이 변경을 시작하기 전에 plan approval을 받지 않으면 더 좋은 방향을 생각할 수 있도록 해줘.
처음에는 관리자 1명만 생성하고, 비즈니스 로직 분석 중 아래 선언된 팀 자원이 부족하면 개발자에게 팀원을 추가해달라 요청해줘.

관리자는 Opus 모델을 이용해주고, 나머지 팀원들은 Sonnet 모델을 이용해줘.

제한사항이 있어.
1. 각 task는 최대한 잘게 쪼개야하고, task들이 승인 -> 수정 작업이 완료되면 task 단위로 커밋을 해야해.
2. 커밋 컨벤션은 docs/convention.md 를 참고해서 작성해줘.
3. 관리자는 모든 작업에 대해서 docs/agent/SAMPLE.md의 형식을 참고하여 문서 관리를 진행해야해.
4. 관리자는 계획 수립 시 각 팀원들이 어떤 작업을 진행하는지 기록을 하고 진행해야해. 
5. 관리자는 비즈니스가 끝나면 각 팀원에게 작업내용을 취합받아 기록을 업데이트해야해.


관리자 : 비즈니스 로직 분석, 팀원들의 설계 검토
팀원 1 : 아키텍처 설계, 기능 구현
팀원 2 : 코드리뷰
팀원 3 : 테스트코드 작성 및 검증
